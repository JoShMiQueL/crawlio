# scrape-sdk — project context

Task-scoped context for agents. The `contextscout` agent reads `navigation.md`
to route tasks to the right files below.

- `navigation.md` — index + quick routes to everything here
- `conventions.md` — stack, structure, style, and scraping-SDK policy
- `commands.md` — build/test/lint commands (fill in once a manifest exists)
- `code-quality.md` — global code-quality standards

`../../AGENTS.md` is auto-loaded by every agent — read it for the project hard rules.
